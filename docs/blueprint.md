# **App Name**: Saligue

## Core Features:

- User Authentication: Secure user registration and login using email.
- Image Upload: Users can upload images of clothing or outfits to find similar items.
- AI-Powered Style Matching: Use AI to analyze uploaded images and suggest visually similar clothing items from available sources.
- Text-Based Search: Users can search for clothing items using text descriptions (e.g., 'red leather jacket').
- Seller Product Uploads: Sellers can upload products with images, titles, descriptions, price, size, color, and contact info.
- Wishlist: Users can save favorite items to a wishlist for future reference.
- Style Recommendations: Tool to suggest trending looks and outfit combinations based on user preferences.

## Style Guidelines:

- Primary color: Deep Indigo (#4B0082) to convey sophistication and style.
- Background color: Light Lavender (#E6E6FA), a soft, desaturated tint of indigo, for a calming backdrop.
- Accent color: Violet (#8F00FF) to highlight key elements and calls to action, contrasting with the primary color.
- Body and headline font: 'Inter', a sans-serif typeface, for a clean and modern user interface.
- Use modern, minimalist icons for easy navigation and visual appeal.
- Mobile-first, grid-based layout to ensure a consistent and responsive design across different devices.
- Subtle animations and transitions to enhance user experience (e.g., loading spinners, smooth scrolling).
